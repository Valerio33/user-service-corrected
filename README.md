## Запуск

1. 
```sql
CREATE DATABASE user_db;
```

2. `src/main/resources/hibernate.cfg.xml`:

- сервер: `localhost:5432`;
- база: `user_db`;
- пользователь: `postgres`;
- пароль: `Cool3654`.


3.  `pom.xml`:

```bash
mvn clean verify
mvn exec:java
```

## Ручная проверка с PostgreSQL

1. Создайте пользователя `Иван`, `ivan@example.com`, `25`.
2. Найдите его по выданному id и через список пользователей.
3. Обновите имя, оставив email и возраст пустыми. Они должны сохраниться. Время создания тоже остаётся прежним.
4. Попробуйте создать другого пользователя с тем же email. Ожидается сообщение об ошибке, после которого меню продолжает работать.
5. Создайте пользователя с другим email. Это проверяет возможность работать после отката предыдущей операции.
6. Попробуйте обновить его email на уже занятый; затем перечитайте пользователя — прежние значения должны остаться.
7. Удалите первого пользователя и повторите удаление. Во второй раз будет сообщение, что он не найден.
8. Проверьте нечисловой id, отрицательный возраст, пустое имя, некорректный email.
9. Завершите приложение пунктом 0.
